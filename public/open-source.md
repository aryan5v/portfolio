# Selected Open Source

## FastVideo

FastVideo is a project from HAO AI Lab focused on accelerated video generation, inference, training, distillation, and related tooling.

Project links:
- FastVideo docs: https://haoailab.com/FastVideo/
- HAO AI Lab: https://haoailab.com
- GitHub: https://github.com/hao-ai-lab/FastVideo

Selected public work:
- FastVideo #1244: https://github.com/hao-ai-lab/FastVideo/pull/1244
- FastVideo #1307: https://github.com/hao-ai-lab/FastVideo/pull/1307

Summary:
- LongCat video generation and self-forcing work
- Training-side model wrapper and causal rollout plumbing
- KV-cache behavior, causal masking, validation, and related practical systems work

## ml-intern

ml-intern is an open-source ML engineering agent from Hugging Face.

Project links:
- GitHub: https://github.com/huggingface/ml-intern

Selected public work:
- ml-intern #186: https://github.com/huggingface/ml-intern/pull/186
- ml-intern #180: https://github.com/huggingface/ml-intern/pull/180

Summary:
- File, image, and dataset attachment flows for web and CLI
- Model routing support
- Practical agent tooling around ML workflows
